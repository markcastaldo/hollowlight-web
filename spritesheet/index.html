Every image in the game, grouped by what it is. The game renders at 640×360 (shown at 2× on screen); world sprites are 16–24 px and bosses up to 120 px. Animated sprites are horizontal strips read left to right (gold lines mark the frames). Towers have a base and a rotating head per upgrade tier (0, 1, 2, then a1–a3 for Ascension). Normal / glow maps are generated from each sprite automatically, so only the colour sprite needs drawing. Click any image to see it larger.

Artists: enter your name and the upload code, then use “Upload alternate” on any sprite. The PNG must be exactly the same size as the original (same frame layout). To see uploads in the game, open Settings (gear, top right of the title screen) and tick “Artist preview”; the newest upload for each sprite is used.
