Hollowlight engine test

A bare Godot 4.7.1 web build with no game code in it. If one of these crashes or freezes in your browser, the problem is the engine (or the browser), not Hollowlight itself.

Test 1: stock engineThe official Godot 4.7.1 web engine (~10 MB download). Test 2: Hollowlight's engineThe slimmed engine the game uses since 0.99.484 (~6 MB download).
  1. Open a test and leave it running for a minute.
  2. Press Fill memory (it climbs to about 800 MB, like the game) and leave it another minute.
  3. Press Busy work and let it finish.
  4. Tell us what happened in each test. If a test crashes, it reports itself to us automatically - no names, just the error and your browser.
